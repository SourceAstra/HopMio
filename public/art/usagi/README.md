# 乌萨奇主题素材

本目录保存产品实际使用的乌萨奇角色与小屋素材。它们根据用户确认的主页效果图制作；效果图属于临时设计资料，不再保存在源码仓库中。

使用内置 imagegen 根据该参考图生成透明 PNG，并在页面中实际检查。

- `companion.png`：共享角色，用于头像、导航、灵感卡片、展厅与陪伴区。
- `cottage.png`：小屋门厅，包含乌萨奇、橘色屋顶、圆木门和花草。
- `app-icon.png`：应用图标源图，用于窗口和网页标签；`app-icon.ico` 为 16–256 像素的 Windows 图标，由 `scripts/build-icons.mjs` 在打包时转换。

应用图标使用内置 imagegen，以 `companion.png` 为角色参考生成：暖金黄色圆角方块，乌萨奇的大头、细长粉色耳朵、圆眼、弯眉、ω 形嘴与脸颊三条刻线；深棕色清晰轮廓，减少纹理以适配小尺寸，无文字与额外装饰，圆角方块外透明。角色身份与产品素材保持一致。

角色生成要求：保留参考图中乌萨奇的奶油黄色毛色、细长粉色内耳、大头短身、亮黑圆眼、弯眉、开心的 ω 形嘴、粉色舌头和带三条刻线的粉色脸颊；温暖手绘水彩与铅笔风格，透明背景，无文字。

小屋生成要求：使用同一角色，橘色屋顶、圆木门、绿植与花朵，乌萨奇在门口迎接；匹配已确认效果图的温暖手绘风格，透明背景，无文字。

代码入口：`src/theme/usagi.ts`。单色打印模型由 `backend/yaha/geometry/usagi.py` 独立生成，通过雕刻表情呈现角色特征。
