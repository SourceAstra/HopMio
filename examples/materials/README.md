# 示例素材 · Sample Materials

本目录内置两组授权明确的示例素材，可直接导入「取材角」体验照片类造物模式（多视角实物还原、照片参考创作等）。

## 猫咪序列/（约 52MB）

大都会博物馆 Open Access 计划的 **CC0 公版照片**，逐角度拍摄序列，适合体验「多视角实物还原」：

- `青铜猫序列/`：Cat Statuette intended to contain a mummified cat（The Met，objectID 544118，CC0）
- `小白猫序列/`：同系列 CC0 馆藏照片
- 各序列预览图与来源清单见 `来源与版权.json`

## 精美照片/（约 34MB）

[Mixkit](https://mixkit.co) 免费素材（Mixkit License：可免费商用、无需署名）的兔 / 松鼠 / 幼犬主题视频与帧序列，适合体验「照片参考创作」与「照片小浮雕」：

- 白绒兔彩蛋、灰兔彩蛋、兔子特写、奶狗与泰迪熊、地松鼠、雪松鼠等
- 授权与原始链接见 `来源与授权.json`

## 使用方法

启动应用后进入「取材角」，新建文件夹并把这些子目录的内容上传（或导入为素材），随后在造物大厅选择对应的照片造物模式。

> 说明：由这些素材生成的模型（blend / stl / glb 等作品文件）体积较大，不随仓库分发，保存在本地作品库 `.state/` 中。
