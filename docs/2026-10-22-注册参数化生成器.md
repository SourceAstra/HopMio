# 注册参数化生成器：流线陀螺 v1

## 使用入口

已有作品 → 参数微调 → 展开“采用参数化生成器” → 流线陀螺 → “采用并生成新版本”。

这一步明确创建一体式新形体，替换当前工作版本，旧模型和旧描述保留在版本记录。不会沿用旧陀螺的两件套、开孔或底座。参考照片保留用于实物比对。生成失败或取消时不替换当前版本。

成功后，现有参数面板直接提供六项参数；也可在 JSON 中填写：

```json
{
  "master_parameters": {
    "diameter_mm": 60,
    "height_mm": 24,
    "dimple_width": 1.1,
    "dimple_depth": 1,
    "blade_relief": 1,
    "twist_deg": 75
  }
}
```

上例相对初始值将凹槽宽度调整为 1.1 倍。未变化的参数不会提交；滑块“松手应用”沿用现有行为，每次成功重算保存新版本。

| 参数 | 默认 | 范围／步长 | 含义 |
| --- | --- | --- | --- |
| diameter_mm | 60 mm | 40–100／2 | 成品宽、深同时复测 |
| height_mm | 24 mm | 16–40／1 | 从底端到最高点的成品高度 |
| dimple_width | 1 倍 | 0.6–1.4／0.1 | 默认凹槽半径倍数，随直径同比变化 |
| dimple_depth | 1 倍 | 0.5–1.5／0.1 | 凹槽造型强度，不作为绝对深度承诺 |
| blade_relief | 1 倍 | 0–1.5／0.1 | 三叶波峰与凹谷强度 |
| twist_deg | 75° | 0–120／5 | 由内到外的螺旋相位变化 |

直径、高度由最终 STL 复测，允许误差沿用 0.05 mm；造型系数不冒充可测尺寸。照片仅作参考，生成器不宣称自动还原照片或 G2 工业曲面验收通过。

## 实现边界

- GeometryPlan v9 保存 `generator: {id, version}`，支持读取原 v3–v8 方案；AI 原有几何步骤契约不变。生成器方案不能混入 steps、source_mesh、surface 或派生绑定。
- `backend/yaha/modeling/generators.py` 注册目录、六项参数元数据和尺寸映射。服务端以注册版本的单位、范围、步长校验，作品数据不能放宽生成器参数范围。
- `backend/yaha/blender/generators.py` 只分派随应用安装的固定生成器。`sculpted_top.py` 负责 v1 曲面。输入不包含 Python、模块路径或用户可执行代码。
- `model.generators.list/apply` 提供目录和采用操作；后续数值修改复用 `model.parameters.describe/apply`。浏览器、桌面和 Go 白名单同步。
- 采用、调参和普通“重新生成”均走本地 `build_direct`，不调用 AI。自然语言微调则将当前已保存 STL 绑定为 source_mesh，再沿现有 AI 局部网格编辑链生成候选版本；不把生成器重写为基本几何。成功后的新网格编辑版本不再具有原六项生成器参数，原生成器版本保留可回退。
- 复用 Blender 超时、取消、面数限制、产物摘要与任务身份验证、封闭实体与尺寸复测、实际网格变化检查、版本保存。保存前重新检查来源版本，资产写入失败按原路径回收。
- STL、GLB、Blend 和八视图由同一个生成任务输出。照片保真状态保持未验收；几何复测通过不等于照片外观通过。
- 新 UI 使用原参数面板深色／Morning Pearl 变量、可换行布局与全宽按钮，适配现有桌面、平板、手机布局。

## 相对用户脚本的曲面修正

1. 曲面计算使用毫米，进入 Blender 前统一除以 1000；继续使用应用的米制场景、毫米 STL 导出契约。
2. 顶底表面共享外缘顶点。采用 `r = R sin(α)` 与共同的中面、半厚度表达式连接上下表面，使外缘两侧具有一致切线，不再分别用不匹配的平方根收边。
3. 渐变使用五次 smoothstep；中心凹槽和底部尖端采用有限的径向多项式过渡，不再声称幂函数就是固定半径球头或 45° 锥面。
4. 叶片起伏受局部半厚度约束。谐波绝对值上界为 0.8，起伏系数上限 1.5，连续公式的上下表面距离至少保留 `0.8 × 半厚度 × cos(α)`（外缘之外的内部为正）。执行时仍检查上下表面交叉，最终网格仍须通过原有几何复测。
5. 固定 96 径向层、192 环向采样，不把无界细分预算交给界面。离散网格和光滑着色不等于解析曲面连续性认证，也不保证所有打印工艺下可直接制造。
