更新：2026-10-15。Goal 是调试造物桌全部功能，覆盖照片实物还原、文字造物的类别与专业造型、可靠微调、参数、版本、导入导出、制造检查和界面操作。名字钥匙扣只是缺陷复现例子。

用户已明确授权「编译、真实生成和测试验收」。以下区分实际通过的案例、已实现的检查和仍未完成的目标。

## 1. 问题出现原因

造物需求经过聊天整理、几何规划和 Blender 执行，但没有把文字、功能孔与成品类别作为贯穿这三层的可执行要求。已有检查主要覆盖总尺寸及拓扑；AI 的说明被当成了已实现的细节。前端更新 React 状态后立即生成，也可能提交旧闭包中的设计。

## 3. 根因证据链

| 缺陷 | 生产者 → 消费者 → 下游结果 |
| --- | --- |
| 无刻字 | AI 将刻字写进 assumptions → prepare 仅编译 steps → Blender 无文字工具 → 空白牌面仍通过总尺寸检查 |
| 椭圆孔 | AI 混用世界轴与旋转前局部轴 → cylinder 先按 XY 非等比定标再旋转 → 实际孔截面为椭圆 |
| 非平整牌面 | 硬质圆角板需求被规划为 cushion → 柔软曲面插值和鼓起处理 → 四周及板面形态与要求不符 |
| 需求错配 | 未支持的模板静默改成 usagi；确认建议依赖异步状态更新 → 当前生成可能读取旧 prompt → 错误作品类别或遗漏补充 |
| 微调越界或假成功 | 只有自然语言局部范围和“几何不同”检查 → 缺少部件范围及成品审阅 → 无关几何变化或未实现要求仍可能保存 |
| 实物变推测造型 | 照片观测不足、工具不可用或重建失败 → 自动选择/回退参数规划 → 推测深度的造型取代实物恢复 |
| GLB 与制造实体不同 | 通用 GLB 保存部件工具，包含布尔之前的形状 → 导出直接读取 glb_id → 下载内容与实际制造网格不同 |
| 曲面细节没有落实 | 普通减法工具位于曲面之外 → 只检查文字布尔效果，其他工具不检查实际体积变化 → 嘴缝等步骤存在但成品没有细节 |
| 扫掠端帽出现环纹 | 端帽固定8段 → 直径30 mm 的真实网格径向误差达到0.07136 mm → 光滑着色不能消除真实轮廓棱线 |
| 照片比对对象错误 | 在制造修补前渲染扫描原件 → 修补、底座和最终 STL 在后面产生 → 比对图不能证明最终制造实体的外形 |
| 制造比对变黑 | 体素重建拓扑丢失投影 UV → 制造副本仍引用原件照片材质 → 无效 UV 采到黑色背景；原始扫描的贴图本身保留有效 |
| 窄屏模型不可见 | 高优先级 full-height 双栏覆盖早期手机断点 → 355 px 页面下模型面板只有约3.6 px → 没有横向溢出也不代表可用 |
| 欢迎预览单位和方向不符 | 从 STL 直接产生 GLB → 没有消费者读取的 yaha_units 标记，也没有 Z-up 到 Y-up 转换 → 与正常 Blender GLB 的渲染契约不同 |
| 作品包丢失草稿语义 | 导出保存审阅记录 → 导入未读取记录 → 未通过的作品恢复后丢失草稿标记 |
| 默认本地流程变成云端流程 | DesignSpec 旧版迁移用 get(provider) 读取缺省值 None → 将其改成 parametric，并误改当前 reconstruction → 本地模板、轮廓与浮雕触发错误的规划要求 |
| 全局挂孔开关无实际孔 | 原生模板按包围盒高度82%放孔 → 孔落在实际几何的空隙 → 布尔未移除体积但任务成功；乌萨奇实测开孔前后体积均为44,888.993 mm³ |
| 空稠密场景继续建网格 | DensifyPointCloud 退出0且保存非空 dense.mvs → 适配器只检查文件大小 → 实际0点仍交给 ReconstructMesh → 进程退出-11 |
| 轮廓偏差被审阅合理化 | 椭球耳廓实际为圆耳 → 原审阅沿目标名称解释为卡通猫 → 未要求抽象改形的关键辨识轮廓也被判为通过 |

## 4. 本质

需求描述、可执行几何和实际产物是不同证据层。尺寸及水密性不能证明文字、孔形或造物类别正确；说明不能代替工具步骤。单张照片不能唯一确定遮挡表面和深度。实物恢复必须使用同一实物的重叠多视角及可追溯的配准观测，参见 [COLMAP 官方教程](https://colmap.github.io/tutorial.html)。

## 5. 本轮源码修复

- GeometryPlan v5 增加 `text` 与 `rounded_box`；v6 增加 `relative_to` 部件局部坐标，编译完整刚体变换，拒绝前向引用、自引用和组合后越界；旧 v3/v4/v5 仍可读取，新 AI 方案使用 v6。
- 文字由真实字体轮廓挤出；字形等比适配指定范围，深度独立定标。字体覆盖全部字符才执行，字体内容参与构建摘要；刻字必须实际改变布尔实体体积。
- 圆角板的平面圆角与板厚独立；边缘另作倒角。禁止文字实体随后被体素重塑抹平。
- 明确指定的引号内刻字必须落实为文字步骤；明确圆孔要求检查旋转前径向尺寸。旧问题方案重新生成时升级规划。
- 整理建议保存完整 Spec 快照，生成显式提交该快照；未注册模板不再被静默替换为角色模板。
- 微调携带可选 `target_part_id`，拒绝改写其他原有部件；允许目标的相对坐标子部件随动，新增工具必须绑定目标子树；失败或取消时前端保留原参数。
- 对参数成品渲染实际六视图，独立审阅类别、结构、文字、修改效果及保留区域；最多一次有依据的自动修订。微调未通过时不覆盖原模型。首次生成未通过时保留明确标记的草稿。AI 审阅仍须结合人工实际查看，不能单独代表专业造型验收。
- 照片默认选择真实表面重建，取消自动回退推测造型；参考创作需主动选择，并明确其深度与背面包含推测。
- GLB 下载及作品包的主 GLB 优先使用实际制造实体；源工程及部件拾取资产保留。
- 普通布尔工具也必须实际改变实体体积；逐步效果写入 manifest，不能以步骤名称代替实际几何。端帽按曲率细分。
- 照片比对使用标定相机渲染最终制造网格，记录 `comparison_basis=manufacturing_mesh` 与 STL 摘要。制造副本移除失效 UV 材质，使用中性几何；扫描原件保留真实贴图。
- 导入作品包保留历史审阅，恢复版本维持待复审状态；不将外部历史结论当作当前通过。
- 手机和平板采用单列可滚动模型、对话与参数面板；聊天仅滚动自身区域。欢迎 GLB 使用米制标记与 glTF Y-up，保留可信乌萨奇 STL。
- 窄屏操作栏参与正常排版，制造指标按两列展示；画布不再继承440 px最小高度而被容器裁掉。无可用微调能力时，输入使用整体灵感模式，禁用不可执行的局部微调入口并说明版本保留。
- Spec 迁移保留缺省 local 与显式 reconstruction；仅把真正过时的提供方迁往当前参数设计。
- 原生模板挂孔沿实际网格投影寻找带边缘余量的位置；记录采样定位依据、孔中心和移除体积，未切入实体则停止。32点投影采样不代表连续壁厚的完整证明。
- 稠密阶段读取真实 PLY 点云，记录 dense_points 并拒绝空点云或非有限坐标，不再以场景文件存在代替表面恢复。
- 任务立即记录实际 reconstruction_plan，使失败后仍能追溯主体区域、照片摘要和尺度参数；工作台及重建报告共用同一报告选择规则，直接展示任务的稠密点数，包括0点。
- 规划与审阅先核对实际轮廓属性和目标的辨识形状，不再允许以未经要求的卡通改形解释关键轮廓偏差。该修改属于模型指令约束，不能保证任意输入都正确。
